# История изменений

## v2.9 — 2026-08-08

- Добавлена отдельная нативная сборка Windows ARM64 на GitHub-hosted runner
  `windows-11-arm` (public preview GitHub Actions).
- ARM64-сборка использует Python 3.12 ARM64 и PyInstaller 6.21.0;
  workflow проверяет, что результат имеет PE-machine `0xAA64`.
- В документации уточнено, что архитектура PKCS#11 DLL должна совпадать
  с архитектурой приложения.

## v2.8 — 2026-08-02

- Добавлены проверка последней подписи и расшифрование последнего шифротекста.
- Исправлены параметры ГОСТ-подписи, ГОСТ 28147-89 и `CTR_ACPKM`.
- Benchmark разделён на setup, прогрев, время PKCS#11-операций и полное время
  измеряемого цикла; добавлены два показателя throughput.
- Улучшены сопоставление ключевых пар, выбор токена, очистка временных ключей и
  диагностика загрузки PKCS#11-библиотеки.
- На macOS по умолчанию используется `/usr/local/lib/librtpkcs11ecp.dylib`.
- Алгоритмы и шаблоны ключей переведены в декларативные таблицы без изменения
  пользовательского поведения.
- Сборка переведена на Actions v7 и PyInstaller 6.21.0.

## v2.4 и ранее

- Базовое TUI-приложение для поиска, создания и удаления ключевых пар, подписи
  файлов и сравнения программного и аппаратного шифрования через PKCS#11.
